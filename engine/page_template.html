        How to import into Paprika

        I'm only permitted to save standard file types, so it arrives as .paprikarecipes.zip, and the .zip has to come off before Paprika will open it. Re-importing a recipe you've exported before shouldn't make a duplicate, because each recipe keeps the same ID every time.

        Mac: in Finder, click the file, press Return and delete .zip from the end of the name (confirm "Use .paprikarecipes"). Double-click it to import. Or double-click the zip to unzip it, then double-click each .paprikarecipe file.

        Windows: turn on View → File name extensions in File Explorer, rename the file to remove .zip, then in Paprika choose File → Import and pick the file.

        Android: Android shows "unrecognised file" until the .zip comes off the name. Open the Files app (Files by Google or your phone's own), go to Downloads, long-press the file, choose Rename (under ⋮ if it isn't shown), delete .zip from the end and confirm the change of file type. Then tap the file and choose Paprika, or in Paprika use Settings → Import and pick it. For a single recipe, Copy for Paprika (below) is quicker.

        iPhone, iPad or Android: open a recipe and press Copy for Paprika. In Paprika, create a new recipe, tap the clipboard button, then highlight each part (title, ingredients, directions) and tap the matching field.
